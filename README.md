# 🏥 Healthcare Doctor Analytics Dashboard

## Project Overview

An interactive **Healthcare Doctor Analytics Dashboard** developed using **Microsoft Power BI** to analyze doctor information, department-wise salary distribution, and staff performance.

## 🎯 Objective

The objective of this project is to analyze doctor and department data, understand salary distribution, compare department performance, and provide detailed doctor-level insights using interactive Power BI dashboards.

## 🛠️ Tools Used

* Microsoft Power BI
* SQL Server
* Power Query
* DAX

## 📁 Dataset

The dataset contains information about **30 doctors** with details including:

* Doctor ID
* Doctor Name
* Department ID
* Department Name
* Joining Date
* Salary

## 📑 Dashboard Pages

### 1. Healthcare Doctor Analytics

Provides an overall summary of hospital doctor and salary information using KPI cards and department-wise visualizations.

Key insights include:

* Total Doctors
* Total Salary
* Average Salary
* Highest Salary
* Total Salary by Department
* Average Salary by Department

### 2. Salary Analysis

Provides a detailed analysis of salary distribution across departments.

Key insights include:

* Total Salary
* Average Salary
* Maximum Salary
* Minimum Salary
* Department-wise Salary Comparison
* Interactive Department Filtering

### 3. Doctor Analysis

Analyzes doctors based on selected departments and salary performance.

Key insights include:

* Average Salary
* Highest Salary
* Average Salary by Department
* Total Salary by Department
* Doctor-level Salary Details
* Department-based Filtering

### 4. Detailed Doctor Analysis

Provides detailed doctor-level information with interactive filters.

Key features include:

* Doctor Filter
* Department Filter
* Joining Date Filter
* Doctor Name
* Department
* Joining Year
* Quarter
* Month
* Day
* Salary
* Doctor Count

## 🧮 DAX Analysis

The dashboard uses DAX calculations for key performance indicators and salary analysis, including:

* Total Doctors
* Total Salary
* Average Salary
* Maximum Salary
* Minimum Salary
* Salary-based aggregations
* Doctor Count

## ⭐ Key Features

* Interactive KPI Cards
* Department-wise Salary Analysis
* Average Salary Comparison
* Total Salary Comparison
* Doctor-level Detailed Analysis
* Joining Date Filtering
* Department Slicers
* Doctor Slicers
* Interactive Dashboard Navigation
* Data Model Relationships
* DAX-based Calculations
